# Partner Finder — Agent Dashboard

## Header
PARTNER FINDER
Client ID / active license indicator
Profile menu

## KPI cards
- Svi kandidati
- Novi
- Visoko interesovanje
- Follow-up danas
- Onboarding

## Candidate table
Columns:
- Kandidat
- Primarni profil
- Sekundarni profil
- Interesovanje
- Kapacitet
- Status
- Poslednji kontakt
- Akcija

Filters:
- status
- primary profile
- interest level
- capacity
- date added

Search by name, email or phone.

## Candidate detail
Sections:
1. Radni profil
2. 5 dimensions
3. Kapacitet
4. Odgovori na 12 pitanja
5. Kontakt and consent status
6. Notes/timeline
7. Follow-up date
8. Actions: Change status, Add note, Schedule follow-up, AI pripremi razgovor

## AI conversation preparation
Input: candidate answers, profile, capacity, interest, agent notes.
Output:
- short candidate summary
- topics to explore
- open questions for conversation
- support/training expectations to clarify
- neutral follow-up draft

AI must not decide employment suitability or make a hiring recommendation.

## Visual system
Dark indigo/navy background, ivory surfaces, champagne-gold accents, azure highlights. Rounded cards, compact data table, clear status badges, responsive desktop/mobile layout.
